# A股交易系统本地筛选器（Python 3.12.10）

这是按你的固定交易系统条件制作的本地 PyCharm 项目。

## 已编码的筛选条件

1. 总市值 30～500 亿元；
2. 主板股票，当前非 ST；
3. 最近一年不允许出现超过 40% 的阶段性上涨；
4. 近半年不能处于“持续趋势下跌”；
5. 当前股价距离近一年最低价不超过 35%；
6. 以下形态满足任意一个即可：
   - 最近 30 个交易日内出现过一次涨停或炸板；
   - 蚂蚁上树；
   - 底部巨量换手。

同时：
- 保存每只股票最近约两年的日K；
- 再次运行时只补充缺失的新交易日；
- 自动删除两年前过旧数据（保留少量计算缓冲）；
- 输出 CSV 和 Excel；
- 所有主观阈值都放在 `config.json` 中，方便修改。

## 1. PyCharm 中配置 Python 3.12.10

建议新建虚拟环境：

```bash
python -m venv .venv
```

Windows 激活：

```bash
.venv\Scripts\activate
```

安装依赖：

```bash
pip install -r requirements.txt
```

在 PyCharm 中将解释器设置为：

```text
项目目录\.venv\Scripts\python.exe
```

确认版本：

```bash
python --version
```

应显示：

```text
Python 3.12.10
```

---

## 2. 填写 Tushare Token

复制：

```text
.env.example
```

为：

```text
.env
```

然后修改：

```text
TUSHARE_TOKEN=你的token
```

不要把 `.env` 上传到公开仓库。

---

## 3. 第一次运行

建议先只测试 20 只：

```bash
python main.py --limit 20
```

确认正常后运行全市场：

```bash
python main.py
```

默认模式等价于：

```bash
python main.py --mode update-and-screen
```

## 4. 三种运行模式

### 更新数据并筛选

```bash
python main.py --mode update-and-screen
```

### 只筛选，不联网更新历史日K

```bash
python main.py --mode screen-only
```

### 只更新本地日K，不筛选

```bash
python main.py --mode update-only
```

## 5. 数据保存位置

每只股票一个 CSV：

```text
data/daily/600000_SH.csv
data/daily/000001_SZ.csv
...
```

重复运行时程序会：

1. 读取本地最后一个交易日；
2. 只请求之后的新数据；
3. 合并并去重；
4. 删除超过约两年的旧数据；
5. 覆盖保存本地文件。

所以不需要每次重新下载两年数据。

## 7. 当前“主观条件”的数学定义

### 最近一年阶段性大涨

计算一年内：

> 任一历史低点 → 后续高点

的最大涨幅。

只要最大阶段涨幅 > 40%，剔除。

### 近半年一直趋势向下

目前定义为同时满足：

1. 半年首尾跌幅 ≥ 25%；
2. 60日均线继续向下；
3. 当前股价低于60日均线。

阈值可在 `config.json` 修改。

### 涨停 / 炸板

因为当前筛选范围限定为普通非ST主板股，所以采用约 10% 涨停制度：

- 收盘涨幅达到约 9.5%：视为涨停；
- 盘中最高价达到约 9.5%，但收盘未维持：视为炸板。

### 蚂蚁上树

当前采用“温和持续抬升”的量化近似：

- 近20日上涨 4%～25%；
- MA5 > MA10 > MA20；
- 上涨交易日占比 ≥55%；
- 单日绝对涨跌幅不超过6%；
- 成交量不能剧烈失真。

这个条件后续最值得根据你的实盘样本继续优化。

### 底部巨量换手

目前定义：

- 当前价格距离一年低点 ≤20%；
- 最新成交量 ≥ 近20日成交量中位数 2倍；
- 最新换手率 ≥3%。

---

## 8. 最值得你后续继续加的条件

你的交易系统里还可以继续加入：

- 最近半年解禁计划 / 已完成解禁；
- 股东减持公告；
- 审计意见是否标准无保留；
- 营收、净利润、净利率、资产负债率；
- 流通市值占比；
- 真实换手；
- 相对天量；
- 跳空缺口；
- 支撑/压力；
- 一年内绝对高度；
- 财报季过滤；
- 交割日 / FOMC / CPI / PCE / 非农等择时过滤；
- ★★★“走势不及预期”卖出复核模块。

---

## 注意

Tushare 不同账号积分/权限不同。如果某接口没有权限，程序会打印错误，但已经成功保存的本地股票日K不会因为中途失败而丢失。

建议第一次先：

```bash
python main.py --limit 20
```

确认 Token 与接口权限无误后再跑全部股票。
