# 甜蜜区筛选器 v4（Python 3.12）

## 本版完成与限制——请先读

本版加入三板块、非ST、流通比例标记、解禁自动证据和公告风险严格过滤。
**减持计划及解禁未完成状态不能由当前 Tushare 接口完整自动获取。需要填写公告核验 CSV；未核验不会进入“筛选通过”。这不是全自动减持计划扫描器。**
没有核验记录时仍可获得“量价候选未通过附加条件”，不要把这张表当作全部条件通过。

## 运行

1. 解压到新的目录，用 PyCharm 打开；解释器继续使用原来的 Python 3.12 环境。
2. 将原项目 .env 复制到本目录（main.py 同级），不要上传密钥。
3. 在终端执行 `python -m pip install -r requirements.txt`。
4. 运行 main.py，选择菜单：更新并筛选、仅更新、仅本地筛选、清理旧数据。
5. 首次输入原数据目录（包含 market.db 的目录），即可复用旧库。先停止旧程序并备份数据库。不要同时运行两个版本。
6. 控制台最后 [目录] 是结果目录；输出位于数据目录/output/运行时间目录。

## 新增条件的明确口径

| 项目 | 本版执行口径 |
| --- | --- |
| 股票范围 | 沪深A股主板、创业板、科创板，排除北交所、B股、当前ST/*ST及退市标识；名单用当前 stock_basic |
| 半年 | 六个自然月，用 DateOffset(months=6)，不是120个交易日；旧量价算法的半年仍为120交易日 |
| 解禁 | 自动排除核验日前六个月至后六个月之间、截至核验日已经公告的解禁记录；包含边界，过去半年已解禁也排除。更早公告仍未完成/延期的事项需公告核验 |
| 减持 | 排除过去六个月公告过减持计划的股票（即使期间已完成）；更早公告而当前尚未完成的也排除。须完整核验计划及进度公告 |
| 流通比例 | 最新有效行情日 daily_basic.float_share / total_share × 100；不是自由流通股本 free_share，不用单次解禁比例替代 |
| 大于98% | 严格 >98%，等于98%标“否”；未知标“未知”。只标记供筛选，不作为硬排除条件 |
| 板块列 | 主板/创业板/科创板，Excel表头下拉可筛选 |
| 未知风险 | 不判作无风险，不进入最终通过名单；量价通过者单列候选 |

用户“近半年”未指定过去还是未来，本版采用上述保守口径；config.json 的 risk.lookback_months / unlock_forward_months 可调整解禁自动查询窗口。人工核验也须遵循同样的配置窗口。当前版股票池和风险核验采用运行当天，因此 --asof 只用于行情截止日期，**不可当作无未来数据的历史回测**。

## 公告核验怎么填写

首次筛选在数据目录生成 `risk_reviews.csv`，每只股票一行。可用文本编辑器或Excel打开并保存为UTF-8 CSV。

| 列 | 填法 |
| --- | --- |
| ts_code | 完整股票代码，例如600000.SH，保留原样 |
| review_date | 实际核验日期YYYYMMDD，例如20261005；仅当日有效，不能把旧审核机械改日期 |
| unlock_status | 无风险 / 有风险 / 待核实 |
| reduction_status | 无风险 / 有风险 / 待核实 |
| source | 公告来源链接、公告编号或可追溯审核记录；空白不认可审核 |
| notes | 说明检查范围、计划公告和完成/终止公告依据 |

“无风险”意味着已经核验完整窗口及更早未完成事项，不意味着“没有看到新闻”。不能仅因没查到持股变动就填无风险。
同一股票当天只能有一条核验记录，source不能为空。自动查到解禁风险时会覆盖人工“无风险”，以避免误放行。新增股票不在旧模板时可自行补行，未补仍按未知。

先运行一次得到量价候选，只核验这些候选即可；填写后选择“仅本地筛选”，不用重新下载。输出中的风险核验日期是运行日期，行情日期另列。

## 不变的量价算法

总市值30～500亿元；一年250交易日；历史不足250根不参与。
前复权计算：一年内严格早于高点的此前最低价至后续最高价最大上涨≤40%；最新收盘距一年最低价≤35%。
持续下跌：收盘<MA60、MA60低于20日前、最近20日最低价在120日最低价1%内，三项同时满足才排除。
三形态任选一：30日内触及实际涨停价；20日蚂蚁上树；30日内底部巨量换手。
蚂蚁参数：20日涨幅4%～25%，上涨天数≥55%，MA5>MA10>MA20，MA20高于5日前，单日涨跌幅绝对值≤6%，量变异系数≤0.8。
巨量参数：信号日收盘距截至该日250日最低价≤20%，成交量≥此前20日中位数2倍，换手≥3%。
创业板、科创板同样比较接口实际涨停价，不使用固定10%近似；其余参数不另行放宽。

## 下载与升级

仍按交易日/接口批量下载、事务保存、断点续跑。旧库自动增加 total_share/float_share，失效旧 daily_basic 批次标记以补齐字段。扩大股票池会使旧范围批次重新拉取校验，不能承诺首次升级不重复请求；已有数据不会删除。
日K保存两年加45天缓冲；清理操作保持旧版口径。
解禁按月下载并立即缓存；同一天续跑跳过完成月份，下一天刷新以发现新公告。
默认全局间隔0.3秒（理论约200次/分钟），trade_cal至少61秒。账号各接口权限/实际额度以服务端为准。
任一接口超限保存状态并停止，不自动重试或继续；权限、网络、结构异常也停止。失败不会被写成“无风险”。
仅本地筛选不联网，股票名单可能过时，输出记录名单日期；要确认当前非ST请先更新名单。

## 输出

筛选结果.xlsx：筛选通过、量价候选未通过附加条件、全部检查、数据问题、运行说明。
全部表设置表头筛选；在“板块”“流通比例大于98%”选择所需值即可。CSV提供相同字段，CSV本身不保存Excel筛选按钮。
market.db保存行情，risk_reviews.csv保存人工核验，request_clock.json保存限速时钟。

## v4新增：三年年报审计

自动调用 Tushare `fina_audit`，逐股保存到 market.db 的 meta 中（audit:股票代码）。官方文档 https://tushare.pro/document/2?doc_id=80 要求至少2000积分，实际权限以账号为准。
每完成一只股票立即保存，当日重跑跳过已完成股票，次日刷新以检查更正公告。空响应保存为已查询但数据缺失，不能当作标准审计意见。接口错误、无权限和超限均停止任务。

### 年度选择

- 当前2026年10月检查2025、2024、2023三个连续年度；只取报告期为12月31日的年报。
- 每年1—4月：若上一年度年报审计已披露，以其为最近年度；否则以前一年度为起点。5月起必须包含上一年度，缺失就标未知，不无限回退到旧年报。
- 每年度取截至核验日最新公告。同日多个意见冲突标未知。
- 标准白名单：标准无保留意见、标准的无保留意见（忽略空白）。带强调事项、持续经营重大不确定性、保留、否定、无法表示等不通过。仅写“无保留意见”且无法区分是否标准的，标未知。
- 少于3个连续年度、空字段、不能识别的标签或快照不是当日，都不判“是”。当前版不是历史回测程序，审计核验日与风险核验日均为运行日期。

### 输出和配置

Excel新增“近3年年报均标准无保留”（是/否/未知）、三个年度各自的年报年度/审计意见/公告日、审计更新日期和说明；所有股票数据表均可下拉筛选。
默认 config.json：

```json
"audit": {"require_standard": true}
```

true：作为硬条件，非标准排除，未知不能最终通过。
false：只显示和提供Excel筛选，不根据审计结果剔除；其他条件仍照常执行。
流通比例>98%仍仅标记、不硬过滤。三板块列照旧。
