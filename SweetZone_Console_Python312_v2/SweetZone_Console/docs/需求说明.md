甜蜜区筛选器需求说明书

版本 2.0    确认日期 2026年9月30日

本说明书定义本地行情维护与候选股票筛选的功能、算法和验收要求，供项目使用、核验及后续修改。程序在 Windows 的 PyCharm 控制台运行，使用 Python 3.12.10 和 Tushare 数据。

关键要求：仅维护沪深主板当前非 ST 股票。任何接口返回频次超限后，保存已完成的数据与状态并停止整个任务，不等待重试，不继续处理下一只股票。

## 1 项目范围与操作

| 项目 | 要求 |
| --- | --- |
| 运行环境 | Windows 与 PyCharm，Python 3.12，控制台交互 |
| 密钥读取 | 读取项目根目录 .env 中的 TUSHARE_TOKEN；离线筛选无需密钥 |
| 数据目录 | 首次由用户输入路径，后续记住；允许通过参数重新选择 |
| 股票范围 | 沪深主板 A 股，当前上市且非 ST；排除其他板块及 B 股 |
| 历史维护 | 两年自然日跨度，加45个自然日计算缓冲；支持增量和续跑 |
| 筛选结果 | 输出通过名单、全部检查结果、数据问题与任务停止记录 |

### 控制台操作

菜单提供更新并筛选、仅更新、仅本地筛选、清理旧数据四项操作。更新并筛选先完成下载，再启动本地筛选。清理只在用户选择该操作时执行。

控制台显示当前阶段、接口、日期或股票代码、完成数量与比例。下载阶段显示保存条数、耗时及动态预计剩余时间；筛选阶段逐只显示通过或排除原因。

本项目只生成候选股票名单，不执行买卖指令，不包含完整财务排雷或历史策略收益回测。

## 2 数据获取与增量维护

| 接口 | 保存内容 | 用途 |
| --- | --- | --- |
| stock_basic | 代码 名称 市场 上市日期 状态 | 建立当前股票池 |
| trade_cal | 交易日期 是否开市 | 确定下载日期 |
| daily | 未复权开高低收 成交量等 | 日K及量价分析 |
| adj_factor | 每日复权因子 | 跨日期价格比较 |
| daily_basic | 每日换手率 总市值 | 市值和巨量换手判断 |
| stk_limit | 每日涨停价 跌停价 | 识别实际涨停与炸板 |

### 批量与完整性

以交易日为单位批量请求，分页收齐后只保存当日已上市且属于当前股票池的记录。默认每页3000条；遇到重复页、异常日期或关键字段缺失时停止，未完成批次不得标记为完成。

先获取最新目标日的四类行情数据，尽早暴露权限或数据入库问题，再补齐历史日期。最新日已缓存时可以跳过。市值不作为维护范围的限制，市值条件只在筛选时应用。

### 缓存与续跑

SQLite按股票代码和日期去重。每个接口日期批次的数据及完成标记在同一事务中提交。重新启动时跳过已完成批次，补齐缺少的接口或日期；股票池变化时重新确认受影响日期的覆盖范围。

股票名单按北京时间每日刷新一次；交易日历缓存最长7天，或范围不足时刷新。默认北京时间18点后使用当日已开市日期；此前使用上个交易日。空表或不完整数据保留为待补状态。

### 旧数据与清理

可通过 --legacy-dir 导入旧项目 data/daily 中的未复权CSV。导入不删除来源文件，不覆盖已存在记录。旧CSV缺少辅助数据和完整批次凭证，首次迁移仍需联网校验及补齐。

清理以运行当天向前两年再加45天缓冲为截止，删除更早记录和完成标记。离开股票池的股票不再更新，已有记录保留至按时间清理。

## 3 筛选基础条件

基础条件必须全部满足，并至少命中下一页定义的一个形态。“一年无大涨”与“阶段涨幅不超过40%”合并为同一条件，不额外加入年度振幅限制。

| 条件 | 统一口径 |
| --- | --- |
| 总市值 | 最近有效日K对应总市值30至500亿元，包含边界。接口总市值单位万元，除以10000换算为亿元。 |
| 观察窗口 | 一年250根、半年120根、形态30根日K；按个股实际有日K的交易日计数，停牌不补造K线。 |
| 复权价格 | 原始价格乘当日复权因子，再除以最新有效日复权因子。开高低收统一使用同一方式。 |
| 阶段涨幅 | 在最近250根日K内，对每一日最高价与严格早于该日的历史最低价比较，取最大涨幅，须不超过40%。 |
| 距一年低点 | 最新复权收盘价除以最近250根日K的最低复权价，再减1，须不超过35%。 |
| 历史不足 | 少于250根日K，或关键价格、复权因子不完整，记为数据不足，不通过筛选。 |

### 持续下跌的排除条件

以下三项同时满足时排除：最新复权收盘价低于当前60日均线；当前60日均线低于20根日K之前的60日均线；最近20根日K的最低价不高于近120根日K最低价的1.01倍。

### 日期与数据状态

当前停牌或最近未成交的股票使用其最近有效日K及对应市值，输出该日期和距目标日的自然天数。最近30日等窗口同样以其有效日K为基准，用户可据日期判断信号是否陈旧。

不得把未下载日期误当停牌。相关计算区间内存在未完成日K批次时，标记数据不足。仅本地筛选使用缓存股票名单，明确显示名单日期；指定过去目标日期也不改变“当前股票池”口径。

## 4 三种形态的统一定义

### 涨停或炸板

检查最近30根日K。未复权最高价达到当日实际涨停价，即视为触及涨停。收盘同样达到涨停价记为涨停；触及但未封住记为炸板。比较容差为0.005元，不使用9.5%的近似涨幅替代。

只有存在有效正数涨停价时才判定。零值或无有效涨停价的交易日不计入触板。实际涨停价记录缺失与“已确认不触板”区分处理，并输出命中日期。

### 蚂蚁上树

以最近20根日K为窗口，以下条件同时满足：

| 指标 | 要求 |
| --- | --- |
| 累计涨幅 | 最新复权收盘价相对20个交易间隔前收盘价，上涨4%至25% |
| 上涨天数 | 20个逐日收益中，正收益比例至少55% |
| 均线排列 | 当前MA5大于MA10，且MA10大于MA20 |
| 均线方向 | 当前MA20高于5根日K之前的MA20 |
| 单日波动 | 窗口内每个复权收盘收益的绝对值不超过6% |
| 成交量稳定性 | 20日成交量总体标准差除以均值不超过0.8；均值须大于0 |

### 底部巨量换手

最近30根日K内，至少有一天同时满足：当日复权收盘价不高于截至当日最近250根日K最低价的1.20倍；当日成交量不低于此前20根日K成交量中位数的2倍；当日换手率不低于3%。成交量基准不包含当日，且中位数必须大于0。

历史低点必须按形态发生日回看，不得使用该日之后的新低。完整覆盖30日巨量判断最多需要279根日K；不足时只能判断具备足够历史的日期。

### 缺失分支的处理

形态分支资料不足时标记未知。基础条件通过且任何分支明确命中即可通过，并保留数据说明；没有明确命中而存在未知分支时记为数据不足。三个分支均可计算且均未命中，才记为形态不符合。

## 5 异常停止与输出要求

### 频次超限的强制停止

正常请求主动限速：全局请求间隔至少1.3秒，trade_cal间隔至少61秒，请求时钟跨启动保存。主动限速发生在请求前；服务端报频次超限后的行为必须是停止，不得进入等待或重试循环。

任一接口报超限后，停止后续全部接口调用及筛选。已提交的数据保持有效，保存停止接口、当前日期或股票、已完成数量、原因及运行状态，并导出已经产生的筛选结果。退出码为2。

接口无权限、网络失败、异常空表或数据结构异常同样停止，退出码为1。Ctrl+C停止时退出码为130。用户排除问题后手动重新运行，继续未完成下载；本地筛选可重新计算。

### 结果文件

| 文件 | 要求 |
| --- | --- |
| 筛选通过.csv | 通过股票、价格、市值、阶段涨幅、距低点幅度、触发形态与日期 |
| 全部检查.csv | 所有已检查股票，含通过或排除原因及最新有效日期 |
| 数据问题.csv | 历史不足、字段缺失或计算失败股票 |
| 任务停止记录.csv | 本次停止类型、接口、原因及进度 |
| 筛选结果.xlsx | 通过名单、全部检查、数据问题、运行说明四个工作表 |
| run_summary.json | 本次状态、目标日期、名单日期、统计、配置及停止位置 |
| screen_checkpoint.jsonl | 逐股即时保存的筛选原始记录，用于异常退出后保留工作 |

每次运行建立独立结果文件夹，不覆盖以前结果。下载阶段停止且尚未开始筛选时，本次筛选表可为空，但必须标记任务未完成，不能声称已筛出零只股票。

扫描结束但存在资料不足时标记 completed_with_data_issues；正常完成标记 completed；停止与中断分别标记 stopped、interrupted。Excel被占用导致导出失败时保留JSONL与状态说明。

## 6 验收标准与实现约束

| 验收点 | 预期结果 |
| --- | --- |
| 限频停止 | 模拟第二个接口限频，之后请求数不再增加，本次不启动筛选 |
| 断点续跑 | 首个接口数据已提交；再次运行只请求其余缺少接口 |
| 事务一致性 | 保存中失败不留下数据部分写入或虚假完成标记 |
| 跨启动节流 | 重新启动仍识别上次trade_cal调用时间 |
| 分页读取 | 收齐多页；出现重复页则停止 |
| 纯本地筛选 | 不创建Tushare客户端，不读取Token，不发网络请求 |
| 价格与边界 | 分红送转按因子修正；40%和35%边界允许，超过则排除 |
| 时间先后 | 同一根K线高低差不直接算阶段涨幅；历史低点不向未来取值 |
| 三种形态 | 分别测试涨停炸板、蚂蚁上树、历史巨量及不满足情况 |
| 中断与清理 | Ctrl+C保留已筛选行；清理保留截止日及之后数据 |

### 交付与验证范围

交付完整源码、参数配置、密钥示例、安装使用说明、本需求文档和离线测试。离线测试覆盖23个场景，使用模拟行情及模拟接口；实际账号权限、Windows文件锁与PyCharm运行仍以用户环境联调为准。

辅助接口有独立权限要求。若账号仅能访问daily，则程序应停止并明确指出所需接口，不得静默改变已确认算法。离线模式采用缓存名单，不能实时识别新的ST状态；本项目不是历史时点股票池回测系统。
